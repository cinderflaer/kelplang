# Pending changes

Scratch file for changes that are not released yet. Gitignored, never committed.

Add a line here when something user-visible lands in `lighthouse`.
**Do not touch `wiki/tooling/lighthouse-changelog.md` until a release is cut**:
that page carries releases only.

When a release is cut (an IntelliJ plugin tag, or a version move in the server),
write its entry in
`wiki/tooling/lighthouse-changelog.md` from this file plus the tag's commits and
the Gitea release body, then wipe this file back to this header. No need to ask
first.

Say which piece each line belongs to: `server` or `intellij`.
